# Surgical Tech Portal TOP プレビュー

ZIPを展開し、`index.html` をブラウザで開いてください。画像、スタイル、動作に必要なファイルはこのフォルダにあります。画像の演出やテーマ選択は、ローカルでも操作できます。施設詳細と公式資料へのリンクを開くときはインターネット接続が必要です。

| ファイル | 内容 |
|---|---|
| `MUSE-PROMPT.md` | 既存サイトへの組み込み指示。Museへの依頼本文として使用 |
| `index.html` | TOP、5章のモーダル、テーマ別一覧。掲載例のJSONも収録 |
| `styles.css` | 画面構成、光の動き、モーダルのワイプ、スマートフォン表示 |
| `top.js` | 冒頭の再生・一時停止、スクロール演出、モーダル、一覧への受け渡し |
| `explorer.js` | テーマの初期選択、画像切替、取り組み・都道府県の絞り込み、TOPへの復帰 |
| `assets/` | 冒頭、縦長の旅、5章の画像。すべてサイトの抽象ビジュアル |

試作のテーマ別一覧は15施設の掲載例です。公開版では最新の監査反映済み施設データと出典を使ってください。本サイトのリポジトリ、公開ページ、データベースには、このパッケージの作成による変更はありません。
