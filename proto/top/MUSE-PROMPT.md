# Surgical Tech Portal｜承認済みTOPとテーマ別一覧の組み込み

添付ZIPを展開し、まず `index.html` をブラウザで操作してください。今回採用するのは、このZIPの画面と動きです。以前のTOP・5章・一覧の素材を参照する場合も、見た目と動作の判断はこのZIPを優先してください。掲載文・施設名・出典には、リポジトリの最新の監査反映済みデータを使います。

## 1. 既存の公開サイトへ組み込む

- 対象は `finefield/surgical-tech-portal.jp`。最新の `main` から作業を始め、TOP `app/page.tsx`、全国一覧 `app/database/page.tsx`、一覧UI `components/database-client.tsx`、施設データ `data/facilities.ts` を確認してください。
- 同梱HTML・CSS・JSは動く見本です。既存のNext.js構成に合わせて組み込み、TOP、全国一覧、施設詳細、特集の既存URLを維持してください。素材は既存の静的ファイルの配置に合わせ、同じ画像を使う箇所は共通参照にしてください。
- 今回の作業対象はTOPの体験とテーマ別一覧への導線です。既存の施設詳細、出典、特集、お問い合わせなど、既存の公開機能は引き続き利用できる状態にしてください。既存の全国一覧は `/database` に集約し、TOPから「消化器外科チームを探す」で入れるようにします。

## 2. TOPの冒頭と縦スクロール

- 背景はダークネイビー。右上の「章を選ぶ」は表示しません。冒頭の主見出しは「外科は、どこまで／未来をひらけるか。」です。ヘッダーの下に、光の管のアップを画面高の約85％に広げます。
- `assets/hero.jpg` をゆっくり拡大・移動させ、管の奥の青白い光と周囲の反射が淡く明滅するようにします。動くのは絵と光です。タイトル、本文、ボタンの位置は固定します。初期表示で画像が描画されたあと、見本のように静かに動き始めるようにしてください。
- 右下のボタンで冒頭の動きを一時停止・再開できます。ボタンの読み上げ名は動作に合わせて更新します。OSの「動きを減らす」設定を尊重してください。
- 「光の先へ ↓」を押すと「見極める。」まで移動します。通常のスクロールでも、冒頭から縦長の光の管へつなぎ目が目立たず、章を順に読めるようにします。下の光はスクロールに合わせて穏やかに明暗ときらめきを変えます。
- 章は「見極める。」「残す。」「挑む。」「つなぐ。」「その先の人生へ。」の順です。途中の各タイトルと下段のビジュアル付き5行は、どちらからも同じ章を開けるようにします。

## 3. 章を選んだときの画面

1. 押したタイトルを短く発光させ、画面中央に細い光が走って、章の絵とフレームが横方向のワイプで開きます。
2. 開いた時点で、**取り組みを具体的に伝える見出しと、3施設の紹介を同時に表示**します。たとえば「残す。」は「胃がんや直腸がんの手術で、機能温存に取り組む外科チーム。」を主見出しにします。「残す。」の大見出しを再掲したり、「消化器外科チームの取り組み」という共通見出しを置いたりする必要はありません。
3. 各施設の行に地域、施設・診療科名、確認済みの取り組みを一文で表示。行を押すと既存の `/facilities/[id]` へ進みます。
4. 3施設の下に、**「このテーマで消化器外科チームを探す →」** を置きます。「取り組みを見る」を押してから一覧が出る二段階モーダルに戻さないでください。
5. 「閉じる」ボタン、Esc、フレーム外から閉じられ、操作した位置とフォーカスに戻れるようにしてください。スマートフォンではパネル内をスクロールでき、見出し、一覧リンク、閉じるボタンが操作できることを確認します。

## 4. 全国一覧とテーマの引き継ぎ

同梱プレビューでは、遷移を一つのHTML内で再現しています。公開版では、各章のリンクから既存の全国一覧 `/database` に進み、下記のテーマを初期選択してください。クエリだけを付ける作業で終えず、一覧側がクエリを読み取って実際に絞り込むところまで実装します。

| モーダルの章 | 一覧のURL | 初期テーマ |
|---|---|---|
| 見極める。 | `/database?theme=insight` | 画像・ナビゲーション |
| 残す。 | `/database?theme=preserve` | 機能温存・再建 |
| 挑む。 | `/database?theme=precision` | AI・機器開発 |
| つなぐ。 | `/database?theme=connection` | 手術教育・技術継承 |
| その先の人生へ。 | `/database?theme=life` | 術後の暮らし・連携 |

- テーマの指定なし・未知のキーは「すべて」。TOP下段の全国一覧ボタンも「すべて」で開きます。URLを共有したり再読み込みしたりしても、指定テーマで表示されるようにします。
- 一覧の見出しは「消化器外科チームを探す」。テーマ切替と同時に、背景の絵、差し色、取り組みの選択肢、結果を切り替えます。取り組みと都道府県を組み合わせて絞り込めるようにし、既存のキーワード検索、地域絞り込み、都道府県単位の案内も利用できるようにします。
- モーダルの3件は入口の紹介例です。一覧は、当該テーマにひもづく確認済みの施設をすべて表示してください。「すべて」は既存全国一覧の全施設を対象とし、件数は実データから計算します。複数テーマに該当する施設は各テーマで表示できますが、「すべて」では施設IDで重複を防ぎます。条件に合う掲載がない場合は空状態を表示します。
- ブラウザの戻る操作でTOPへ戻るとき、選んだ章付近に戻れるようにしてください。モーダルから一覧へ進む操作は同一タブ内で行います。

## 5. 紹介文・出典・テーマ付け

- プレビュー内の掲載例JSONはデザイン確認用です。公開データへ一括転記せず、施設IDで現在の名称、診療科、紹介文、タグ、詳細URLと突合してください。監査で削除・変更した旧表現、古い名称、リンク切れを戻さないでください。
- モーダルに出す3施設は、監査反映済みの記述と一次資料でテーマに適合することを確認します。確認済みの候補が不足する場合は、使えた件数と不足理由を報告してください。件数をそろえるための推測で施設や文を足さないでください。
- テーマはロボット保有の有無だけで付けないでください。術前画像解析、術中ナビゲーション、手術支援AI、映像・AR・VRを使った教育、遠隔指導、術後フォローなど、施設ごとの具体的な取り組みにひもづけます。
- 研究、模擬手術での実証、薬事承認、診療での運用、教育利用を区別してください。若手が担当できる手技、配属・異動・募集状況は公式案内に記載がある範囲で掲載します。

## 6. 実装後の確認と報告

1. PCとスマートフォンで、冒頭画像・文字の読みやすさ、動きの再生・停止・再開、スクロール先を確認する。
2. 途中の5タイトルと下段の5行からモーダルを開き、章の絵・見出し・施設行・一覧リンクが対応していることを確認する。Escと「閉じる」で元の位置に戻ることも確認する。
3. モーダルの5つのリンクを実際に押し、テーマ付きURL、選択状態、背景画像、結果が一致することを確認する。直リンク、再読み込み、戻る操作、都道府県・取り組みの絞り込み、施設詳細への遷移も確認する。
4. 「すべて」で全国一覧の全施設にアクセスできること、監査で修正した文やリンクが古い状態に戻っていないことを確認する。
5. 最後に、変更したファイル、プレビューURL、5章の接続先、確認した操作、公開文面で保留した箇所を報告する。プレビューで確認した結果と本番へ反映した結果を区別する。
